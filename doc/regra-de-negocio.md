RN01: Apenas usuários cadastrados e autenticados podem acessar o sistema.

RN02: Somente administradores podem cadastrar e gerenciar usuários.

RN03: Cada usuário deve possuir um login único.

RN04: Cada sensor deve possuir um identificador único.

RN05: Cada sensor deve possuir um status: operacional, com erro ou em manutenção.

RN06: O sistema deve atualizar e exibir o status dos sensores.

RN07: Sensores que possuem dados armazenados não podem ser removidos.

RN08: Dados históricos dos sensores devem ser preservados.

RN09: Usuários autorizados podem gerar relatórios em tempo real ou por período.

RN10: O acesso às funcionalidades deve respeitar o nível de permissão de cada usuário.

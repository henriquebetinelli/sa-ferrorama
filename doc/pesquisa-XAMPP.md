# XAMPP

O XAMPP é um pacote gratuito e de código aberto usado para criar um ambiente de desenvolvimento web local no computador. Ele permite desenvolver e testar sites e sistemas sem precisar de uma hospedagem na internet.

O nome XAMPP está relacionado aos seus principais componentes: Apache, MySQL/MariaDB, PHP e Perl.

---

# Principais componentes

O principal componente é o **Apache HTTP Server**, responsável por funcionar como servidor web e exibir páginas no navegador. O MariaDB é utilizado para armazenar e organizar dados das aplicações, como usuários, produtos e informações de sistemas. Já o PHP é a linguagem usada para criar páginas dinâmicas e funcionalidades dos sites.<br>O pacote também inclui o phpMyAdmin, uma ferramenta gráfica que facilita o gerenciamento do banco de dados pelo navegador.

---

# Instalação

**A instalação do XAMPP é simples:** o usuário deve baixar o instalador no site oficial, executar a instalação e iniciar os serviços do Apache e do MySQL no painel de controle do programa. Depois disso, é possível acessar o ambiente digitando **“localhost”** no navegador. Os arquivos dos projetos ficam normalmente na pasta **“htdocs”.**

---

# Importância

O XAMPP é muito importante para o desenvolvimento local porque permite testar sistemas de forma rápida, segura e sem internet. Ele facilita o aprendizado de programação web, ajuda na identificação de erros e possibilita que aplicações sejam desenvolvidas e testadas antes da publicação em um servidor real.

**Requisitos Funcionais**

RF01. O sistema deve permitir que usuários realizem login utilizando suas credenciais.
RF02. O sistema deve permitir o cadastro de novos usuários.
RF03. O sistema deve permitir editar os dados dos usuários cadastrados.
RF04. O sistema deve permitir excluir ou desativar usuários.
RF05. O sistema deve diferenciar usuários de acordo com seu nível de acesso.
RF06. O sistema deve permitir cadastrar sensores vinculados aos trens.
RF07. O sistema deve permitir visualizar os sensores cadastrados.
RF08. O sistema deve permitir consultar o status atual dos sensores.
RF09. O sistema deve permitir alterar o status de um sensor.
RF10. O sistema deve registrar os dados coletados pelos sensores.
RF11. O sistema deve permitir consultar o histórico dos dados dos sensores.
RF12. O sistema deve permitir identificar sensores que apresentam falhas ou erros.
RF13. O sistema deve permitir gerar relatórios a partir dos dados registrados.
RF14. O sistema deve permitir consultar informações dos trens monitorados.
RF15. O sistema deve permitir ao usuário encerrar sua sessão através da função de logout.


**Requisitos Não Funcionais**

RNF01. O sistema deve possuir uma interface simples e intuitiva.
RNF02. O sistema deve possuir controle de acesso baseado no tipo de usuário.
RNF03. As senhas dos usuários devem ser armazenadas de forma segura, utilizando criptografia/hash.
RNF04. O sistema deve proteger os dados contra acessos não autorizados.
RNF05. O sistema deve apresentar as informações dos sensores de forma clara e organizada.
RNF06. O sistema deve manter a integridade dos dados armazenados.
RNF07. O sistema deve possuir tempo de resposta adequado para consultas e operações comuns.
RNF08. O sistema deve ser compatível com navegadores web modernos.
RNF09. O sistema deve permitir manutenção e atualização do código sem comprometer os dados existentes.
RNF10. O sistema deve manter os registros históricos dos sensores para consultas e relatórios.
